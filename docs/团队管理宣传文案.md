# Empower Your Team with Intelligent API Management
## Take Control of Your Team's API Usage, Costs, and Consumers — All in One Place
### Why Team Management?
In today's fast-paced AI-driven workflows, teams need more than just API access — they need visibility, control, and optimization . Our Team Management module gives administrators a comprehensive toolkit to manage departments, track consumer behavior, monitor API usage, and optimize costs across the entire organization.

### Key Features 1. Hierarchical Department Management
Organize your team with a clear department tree structure . Create nested departments, assign department codes, and visualize reporting lines at a glance. Whether your organization is flat or deeply layered, our intuitive tree view keeps everyone in their place.

- Tree-based department visualization
- Drag-and-drop hierarchy management
- Department-level cost tracking with custom department codes 2. Consumer Lifecycle Management
Manage every API consumer from creation to retirement. Assign consumers to departments, set types and roles, and track their activity in real time.

- Two-column streamlined form for quick onboarding
- Type-first selection for clear categorization
- Full profile support: name, email, phone, position, department
- Real-time consumer activity tracking 3. API Key Management with Smart Associations
Link API keys to specific departments and consumers for granular access control. When you select a department, the system automatically filters available consumers — no more mismatched assignments.

- Department-aware consumer filtering
- Secure key generation and rotation
- Per-key usage and cost attribution 4. Comprehensive Team Analytics
Make data-driven decisions with rich, multi-dimensional analytics:

- Usage Trends : Switch between daily and hourly granularity to spot patterns in real time
- Platform Distribution : See which AI platforms consume the most resources
- Consumer Rankings : Identify top consumers with flexible time ranges — today, last 3/7/15/30/90 days, this month, last month, or any custom date range
- Cost Insights : Track total requests, input/output tokens, and actual costs at a glance 5. Role-Based Team Member Management
Control who can do what with granular role assignments. Add admins, invite members, and manage pending invitations — all from a single dashboard.

- Admin and member roles
- Invitation workflow with pending state tracking
- Active member statistics at a glance 6. Real-Time Cost Optimization
Every request is tracked. Every token is counted. Every cost is attributed. With our 1-minute aggregation engine, your analytics dashboard reflects real-time usage — not stale data from hours ago.

- 1-minute data aggregation for near real-time insights

# 智能团队管理，让 API 调用尽在掌控
## 部门、消费者、密钥、用量、成本 —— 一站式管理，全景可视
### 为什么需要团队管理？
在 AI 驱动的高效工作流中，团队需要的不仅仅是 API 访问权限，更需要 全局可视、精准管控和成本优化 。我们的团队管理模块为管理员提供了一套完整的工具链，覆盖部门管理、消费者追踪、API 用量监控和成本分析，让组织的每一份资源都用在刀刃上。

### 核心功能 1. 层级化部门管理
通过清晰的 树形结构 组织团队，创建嵌套部门、分配部门编码，一目了然地查看汇报关系。无论您的组织是扁平结构还是多层级架构，直观的树形视图都能让每个人各归其位。

- 树形部门可视化展示
- 部门编码自定义，便于成本归集
- 部门级别的用量与成本追踪 2. 消费者全生命周期管理
从创建到停用，管理每一个 API 消费者。将消费者分配到部门，设置类型和角色，实时追踪其活动状态。

- 两列式表单，快速完成信息录入
- 类型优先选择，清晰分类管理
- 完整档案支持：姓名、邮箱、电话、职位、部门
- 消费者活动实时追踪 3. 智能关联的 API 密钥管理
将 API 密钥关联到特定部门和消费者，实现精细化访问控制。选择部门后，系统自动筛选该部门下的可选消费者 —— 告别错配烦恼。

- 部门感知的消费者智能联动
- 安全的密钥生成与轮换机制
- 单密钥级别的用量与成本归因 4. 全维度团队数据分析
用丰富的多维度分析面板，做出数据驱动的决策：

- 使用趋势 ：支持按天/按小时粒度切换，实时发现用量规律
- 平台分布 ：直观展示各 AI 平台的资源消耗占比
- 消费排行 ：灵活选择时间段 —— 今天、近3/7/15/30/90天、本月、上月，或自定义任意日期范围，精准定位高频消费者
- 成本洞察 ：总请求数、输入/输出 Token、实际成本，一目了然 5. 角色化团队成员管理
精细化的角色分配，掌控每个成员的权限边界。添加管理员、邀请成员、管理待处理邀请 —— 一切尽在一个面板。

- 管理员与普通成员角色体系
- 邀请流程支持，待处理状态实时追踪
- 活跃成员统计一览无余 6. 实时成本优化
每一次请求都被记录，每一个 Token 都被计算，每一笔成本都被归因。依托1分钟级聚合引擎，分析面板反映的是实时用量 —— 而非数小时前的过期数据。

- 1分钟数据聚合，近实时洞察
- 按消费者、按部门、按团队的多维成本拆解
- 历史趋势分析，助力预算规划
